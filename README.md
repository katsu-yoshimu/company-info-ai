# アプリケーション利用手順書 (マニュアル)

本ドキュメントでは、配布用ZIPパッケージに含まれる各種ファイルのセットアップから、実行ファイル（`.exe`）の利用方法、ログの確認手順までを解説します。

---

## 1. パッケージ構成

ダウンロードしたZIPファイル（例: `app_package_yyyymmdd.zip`）には、以下のファイル・フォルダが含まれています。

| ファイル / フォルダ名 | 種別 | 説明 |
| --- | --- | --- |
| **`main.exe`** | 実行ファイル | `main.py` から単一ファイル形式（Onefile）でビルドされた実行用プログラムです。 |
| **`config.ini`** | 設定ファイル | APIキーや動作パラメータなどを保持する設定ファイルです。 |
| **`input/companies.csv`** | 入力サンプル | 本ツールで処理対象とするデータファイルのサンプルです。 |
| **`logs/app_yyyymmdd.log`** | ログサンプル | 実行時のログ（出力・エラー履歴）のサンプルです。 |

---

## 2. ZIPファイルの解凍手順

1. **ZIPファイルの選択**
  
    ダウンロードした `app_package_yyyymmdd.zip` を右クリックします。

2. **解凍操作**
   * Windowsの場合: **「すべて展開...」** を選択し、展開先のフォルダ（デスクトップや任意の作業フォルダ）を指定して **「展開」** ボタンを押します。
   * サードパーティ製ツール（7-Zip, WinRAR等）をご利用の場合は、「ここに解凍」または「フォルダに解凍」を実行してください。

3. **展開結果の確認**
  
  展開されたフォルダを開き、上記の「1. パッケージ構成」に記載されているファイルが一通り揃っていることを確認します。

> **注意:** ZIPファイル（圧縮フォルダ）状態のまま `.exe` を直接起動すると、設定ファイルや入力ファイルが正常に読み込めずエラーになります。**必ず解凍してから**ご使用ください。

---

## 3. 設定ファイル（config.ini）の修正方法

APIとの連携に必要な認証情報（APIキー等）を設定します。

### 3-1. APIキーの取得手順

ご利用になるLLMサービスに合わせて、事前に対象プラットフォームでAPIキーを発行してください。

---

#### 【パターン A】 Claude (Anthropic) の APIキー作成手順

1. **Anthropic Console へアクセス・ログイン**

    [Anthropic Console (console.anthropic.com)](https://console.anthropic.com) にアクセスし、アカウントを登録またはログインします。

2. **クレジットカード（クレジット）の設定**
  
    「Settings」 ＞ 「Billing」 からクレジットカードを登録し、利用枠（クレジット）をチャージしておきます。

3. **API Keys ページへ移動**

    左側メニューまたはダッシュボードから **「API Keys」** を選択します。

4. **APIキーの新規作成**

    **「Create Key」**（または「New Key」）ボタンをクリックし、任意のキー名（例: `My App Key`）を入力してキーを発行します。

5. **APIキーの保存**

     `sk-ant-` から始まるAPIキーが表示されます。**このキーは一度しか表示されません**ので、画面を閉じる前に必ずコピーして保存してください。

---

#### 【パターン B】 Gemini (Google AI Studio) の APIキー作成手順

1. **Google AI Studio へアクセス**

    [Google AI Studio](https://aistudio.google.com/) にログインします。

2. **APIキーの発行**

    左メニューの **「APIキー」** (API Keys) をクリックし、**「API キーを作成」** を選択します。

3. **APIキーの保存**

    表示された `AIzaSy` から始まるAPIキーをコピーします。

---

### 3-2. config.ini の編集手順

1. **設定ファイルをテキストエディタで開く**

    `config.ini` を右クリックし、**「プログラムから開く」** ＞ **「メモ帳（Notepad）」** またはご利用のテキストエディタ（VS Code, サクラエディタ等）を選択します。

2. **APIキーの書き換え**

    ファイル内の `[LLM]` セクションを探し、取得したAPIキーを設定します。

    **【Claude を使用する場合の例】**

    ```ini
    [LLM]
    provider = anthropic
    api_key = sk-ant-api03-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
    model = claude-3-5-sonnet-latest

    ```

    **【Gemini を使用する場合の例】**

    ```ini
    [LLM]
    provider = google
    api_key = AIzaSyDxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    model = gemini-2.5-flash

    ```

3. **保存して閉じる**

    編集が完了したら、`Ctrl + S` （または「ファイル」＞「上書き保存」）で上書き保存し、エディタを閉じます。

## 4. 入力ファイルの設定方法

本アプリケーションで処理させたいデータを準備・配置します。

1. **入力データの準備**

    処理対象のデータ（CSVファイル、テキストファイルなど）を準備します。

2. **ファイルの配置**

    `main.exe` と**同じフォルダ内**に、処理対象ファイルを配置します。

3. **ファイル名の確認・設定**

   * デフォルトの入力ファイル名（`input/companies.csv`）に合わせるか、引数で入力ファイル名の指定がある場合はそちらのパスに合わせて配置してください。

---

## 5. 実行ファイル（exe）の使用方法

### パターン A: 通常起動（ダブルクリック）

1. `main.exe` をダブルクリックして起動します。
2. コマンドプロンプト画面（黒いウィンドウ）が開き、処理が開始されます。
3. 処理完了メッセージが表示され、画面が閉じる（またはキー入力待ちになる）まで待ちます。

### パターン B: コマンドプロンプトから起動（推奨）

エラー発生時のログ画面維持や、引数を指定したい場合はコマンドプロンプトからの実行を推奨します。

1. エクスプローラーのアドレスバーに `cmd` と入力して `Enter` キーを押します。（現在フォルダでコマンドプロンプトが開きます）

2. 以下のコマンドを入力して実行します。

    ```bat
    main.exe --input input/companies.csv
    ```

3. 実行ログがリアルタイムで画面上に表示されます。

---

## 6. ログファイル（log）の確認方法

処理結果や発生したエラーの詳細は、ログファイルに自動的に記録されます。

1. **ログファイルの場所**

    `main.exe` と同じフォルダ内に作成される `logs/app_yyyymmdd.log` を確認します。

2. **ログファイルの確認**

    メモ帳などのテキストエディタで `logs/app_yyyymmdd.log` を開きます。

3. **ログの確認ポイント**

   * `INFO`: 通常の動作ログ（処理完了、ファイル読み込み成功など）
   * `WARNING`: 警告（軽微な問題）
   * `ERROR` / `CRITICAL`: エラー発生（APIキー不一致、入力ファイル未検出など）

    **【エラー発生時の対処例】**

    * **「API Key not found」等のエラー**: `config.ini` の `api_key` が正しく入力されているか確認してください。
    * **「File not found」等のエラー**: 入力ファイルが `main.exe` と同じ階層に置かれているか、ファイル名が正しいか確認してください。
